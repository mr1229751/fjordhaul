FJORDHAUL is an original Canvas 2D chase-view flight game. You fly a prop cargo plane over a dusk fjord archipelago, hauling freight between island airstrips: thread checkpoint rings down the fjord, drop supply crates onto marked island zones, and fly a storm run on short fuel to a short strip. The flight model rewards throttle and turn discipline — speed bleeds in climbs and hard turns, the wing stalls if you get slow, and fuel and hull damage turn every sortie into decisions. Three missions form a campaign with landing grades (Gentle / Firm / Hard), scores and stars, all drawn and sounded by the game's own code with no external assets.

Fly with W/S for throttle, the arrow keys (or mouse) to pitch and bank, Space to drop a crate, P or Esc to pause and M to mute.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
